inbox-attachment-automator is a Python desktop application designed to simplify document management by automating Gmail attachment downloads and tracking processed files.

### Features

- Automatic Gmail attachment downloads
- Duplicate detection and file recovery
- Local download history with SQLite
- Desktop interface with CustomTkinter
- Branded UI with dashboard, documents, clients, and settings sections

### Tech Stack

- Python ┬À CustomTkinter
- Gmail API ┬À OAuth 2.0
- SQLite

### Project Status

The Gmail download workflow has been tested with sample PDF, PNG, XLSX, and DOCX attachments. Duplicate detection and file recovery have also been tested.

The desktop application and its features are still in development.

### Getting Started

Setup instructions and configuration details will be documented as development progresses.

### Security

OAuth credentials, access tokens, databases, and private documents must never be committed to the repository. 

### Testing

The current development tests include basic SQLite uniqueness checks and manual attachment-download tests.

More automated tests are planned to improve reliability and cover error handling, Gmail search behavior, and attachment processing.
